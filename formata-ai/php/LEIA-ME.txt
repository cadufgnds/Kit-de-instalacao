FORMATA.AI — FERRAMENTA PARA O HUB (VERSÃO PHP)
================================================

O que é
-------
Formata e pagina documentos operacionais para a base I.Ajuda, seguindo as
Diretrizes Formata.AI v2.6, sem alterar nenhum caractere do texto.
Não usa banco de dados e não guarda os documentos: cada um é processado e
descartado na hora.


Requisitos do servidor
----------------------
- PHP 5.6 ou superior (testado em 5.6, 7.0, 7.4, 8.2 e 8.3).
- Extensão mbstring do PHP (vem ativa na maioria das hospedagens).

Funciona dentro do hub ou sozinha, em qualquer site com PHP.


Como instalar
-------------
1. Extraia o arquivo formata-ai-php.zip. Ele contém uma pasta chamada formata-ai.

2. Copie a pasta formata-ai inteira para dentro da pasta do hub no servidor,
   ao lado das pastas admin, assets, includes...

       hub/
         admin/
         assets/
         includes/
         formata-ai/      <- a pasta nova
         index.php
         ...

3. Confira o servidor no navegador:
       https://ENDERECO-DO-HUB/formata-ai/diagnostico.php
   Deve aparecer "Tudo certo". Se aparecer algum item com "Falha", a própria
   página explica o que falta. Envie uma foto dela ao responsável.

4. Abra a ferramenta:
       https://ENDERECO-DO-HUB/formata-ai/
   Cole um texto, clique em "Formatar documento" e confira o resultado.


Exigir o login do hub (recomendado)
-----------------------------------
Abra formata-ai/config.php e preencha 'arquivo_autenticacao' com o mesmo
arquivo que as outras páginas do hub usam para verificar o login. Exemplo:

    'arquivo_autenticacao' => '../includes/verifica-login.php',

Com isso, quem não estiver logado no hub não consegue usar a ferramenta.
Mudanças em config.php podem levar alguns segundos para valer (cache do PHP).


Problemas comuns
----------------
"Esta página não está funcionando — HTTP ERROR 500" (página em branco)
    O PHP do servidor parou com um erro. Abra formata-ai/diagnostico.php e
    envie uma foto da página. Se o diagnóstico também não abrir, o servidor
    não está executando PHP nessa pasta.

"O servidor encontrou um erro ao abrir a ferramenta"
    A mensagem vermelha diz em qual arquivo e linha. Se citar um arquivo do
    hub (por exemplo, o de login), confira 'arquivo_autenticacao' em config.php.

"A API do Formata.AI não respondeu"
    A pasta foi copiada incompleta (faltam api ou nucleo) ou o servidor não
    está executando PHP nessa pasta. Refaça o passo 2 e teste o passo 3.

"Sessão do hub encerrada"
    O login do hub expirou. Entre de novo no hub e volte à ferramenta.

O diagnóstico mostra falha na versão do PHP ou na mbstring
    Peça ao responsável pela hospedagem para atualizar o PHP (5.6 ou
    superior) ou ativar a extensão mbstring.

Arquivo .docx recusado
    Ainda não é aceito. Copie o texto e cole na página, ou salve o documento
    como .txt ou .md em UTF-8.


Configurações (config.php)
--------------------------
limite_bytes          tamanho máximo do documento (padrão: 1 MB)
limite_linhas         linhas por documento (padrão: 20.000)
tempo_limite          segundos por formatação (padrão: 15)
arquivo_autenticacao  login do hub (veja acima)
registrar_log         registra no log do PHP só tamanho, resultado e duração;
                      nunca o conteúdo dos documentos
diagnostico_ativo     liga ou desliga a página diagnostico.php
