# Marca

- `marca.css` concentra as cores, a tipografia e os raios da interface. A página e a pré-visualização só usam essas variáveis.
- `fontes/` é a pasta para os arquivos licenciados da **Vivo Type** (`VivoType-Regular.woff2` e `VivoType-Bold.woff2`). Ela fica vazia no repositório, porque os arquivos da fonte não podem ser distribuídos sem licença. Siga as instruções no início de `marca.css` para ativar a fonte.
- `icone/` guarda o ícone da página, usado no cabeçalho, no rodapé e como favicon (`icone-16/32/48.png`, `../favicon.ico`), além do ícone para tela inicial do iOS (`icone-180.png`). `icone-512.png` é a matriz, com fundo transparente fora do círculo. Para trocar o ícone, substitua os arquivos mantendo os nomes e os tamanhos.
- O logotipo da Vivo não é reproduzido. A identificação usa a palavra **Formata.AI** em texto. Se houver autorização para usar o logotipo oficial, coloque o arquivo SVG aprovado aqui e troque o conteúdo do link `.logo` em `index.html`.

As cores de `marca.css` são valores de referência da identidade Vivo. Confirme cada uma no manual de marca vigente antes da publicação.
